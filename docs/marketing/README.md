## The rule that governs all of it

**No claim outruns a measurement, and every number carries the command that reproduces it.**

That is not modesty. The audience is people who have been lied to by every landing page they
have read, and the one thing a competitor with more money cannot copy is a number they would
have to stop selling something to publish.

Three consequences worth stating once:

1. **Modafied is never sold.** No call to action on a scorecard, no paid placement, no
   appearance in a Trooth or KouroB price table or feature list. It takes no revenue from any
   party it grades. The funding arrangement is published with a number on it.
2. **Synthetic stays labelled synthetic.** The cost curve today is a thirty day replay of the
   example node, and the copy says so in the same sentence as the number.
3. **The gaps stay on the page.** Every piece carries what is not built yet. It is the
   cheapest credibility available and it costs nothing, because the gaps are in the
   repositories anyway.

## Before anything ships

- It matches the current published scorecards and the current state of the repositories.
- It contains no line from the forbidden list in `MESSAGES.md`.
- Its phase gate in `SEQUENCE.md` is met.
- It has no em dashes, per the Trooth site style rules.
