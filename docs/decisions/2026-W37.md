# Decisions, week of 2026-09-08

Decisions too small for an ADR, per `AGENTS.md` section 7. Append-only.

## 2026-09-09 · M0 · decisions made without asking

Recorded under `docs/DEFAULTS.md` ("choose, record, continue"). Each is reversible.

1. **M1 acceptance tests are `xfail(strict=True)`, not plainly failing.** The brief asks
   for the M1 acceptance tests as failing tests (section 16 step 6) *and* for CI green on
   M0 (section 12). Strict xfail satisfies both: the tests are red, CI is green, and the
   marker cannot survive the feature landing, because an unexpected pass is a failure.
   Written into `docs/DEFAULTS.md` under Tests. Reversible in one line if the human wants
   them plainly red.

2. **The AGENTS.md section 4 rails are pytest tests, not CI grep steps.** Brief section 9
   says CI greps for them. Making them tests means they also run locally before the push,
   and they gain readable failure messages. CI runs them in the `pytest` step, so the
   enforcement is unchanged. See `tests/test_rails.py`.

3. **`typer` for the CLI.** Not named in the brief. Permissive, small, generates the
   `--help` that M0 is measured on. Under the `docs/DEFAULTS.md` dependency rule, so no
   ADR. `duckdb` and `pyarrow` exceed the 5 MB rule but are named in brief section 9 and
   decided in ADR-0001, which is the ADR that rule asks for.

4. **Unimplemented CLI commands exit 2, not 0.** Stricter reading, per DEFAULTS.md
   ("choose the stricter reading"): a script that calls a stub should fail loudly rather
   than appear to succeed. Each prints its milestone and the brief section.

5. **Every module carries `__milestone__`.** Enforced by `tests/test_rails.py`. It makes
   the tree self-describing and keeps `--help` honest as modules land.

6. **The rail on `data/silver` and `data/gold` is "no module but `gate.py` names the
   path"**, which is stricter than "no module but `gate.py` writes it" and much easier to
   check. Readers go through the `Store` interface by logical table name (ADR-0001).

7. **`bd`'s managed block lives in `AGENTS.md`, not `CLAUDE.md`.** The brief specifies
   `CLAUDE.md` as a one-line pointer. `bd init` appended to both and duplicated itself
   under a second marker; the duplicate was removed and `AGENTS.md` section 9 records that
   section 2 wins where the two protocols disagree.

8. **Beads issue prefix is `kb`.** Short, unambiguous, does not collide with the `bd`
   command name.

## 2026-09-10 · protocols and evolution · decisions made without asking

9. **`docs/protocols/` and `docs/integration/` are new directories**, not in brief section
   11. Wire contracts are specs, not decisions, and they were being written into ADRs where
   they did not fit. Recorded in `docs/DEFAULTS.md` under Protocols, and in `AGENTS.md`
   section 7.

10. **Five extension URIs under `https://kourob.org/ext/`**, one per KNP spec, rather than
    one omnibus extension. Per-spec URIs let a caller activate provenance without activating
    metering, which is the common case for a read-only client. Cost: five URIs to keep
    alive instead of one.

11. **`kourob.org` is assumed as the extension namespace and is not registered.** ADR-0006
    notes this. The URIs are opaque identifiers and nothing dereferences them today, so this
    is not blocking — but it becomes a real problem the moment a third party implements
    against them. Registering the domain, or moving to `w3id.org`, is a human decision.

12. **The evolve objective is cost per *settled* request** (ADR-0007), which is a stronger
    claim than the brief makes. The brief's cost-per-request target in `GOAL.md` is
    unchanged; the denominator is now narrower, so the target is harder, not easier. If this
    turns out to make the 5x target unreachable, the honest fix is to report both numbers,
    not to widen the denominator.

13. **A T0 rule needs exact replay, not a tolerance** (ADR-0008). This will slow the cost
    curve. It is the price of `derived` meaning what it says.

## 2026-09-10 · running infrastructure · decisions made without asking

14. **`src/kourob/node.py` and `src/kourob/serve.py` are new modules**, not in brief §11.
    `init`, `ingest`, `query`, `doctor`, the MCP port and the REST port were each about to
    assemble the same four objects — manifest, store, gate, ledger — in the same order.
    `node.py` is that assembly; `serve.py` is the one place an answer is built, so it is the
    one place the KNP-0 invariants can be enforced.

15. **A fourth determinism class, `declared`.** Found by a test: `list_schemas` returns the
    node's own contracts, which are not derived from events and have nothing to cite.
    KNP-0 I2 needed an exemption for **introspection** — a node reciting its own signed
    declaration — distinct from the refusal exemption. Narrow on purpose: it covers the node
    describing *itself*, never the node describing anything else.

16. **A small ODCS reader now, `datacontract-cli` later.** `schema/loader.py` covers the
    subset the gate needs (required, logical type, enum, range, pattern). Shipping it first
    means the gate can be built and measured today, and it is replaceable because nothing
    outside that module knows the file format. Codegen and breaking-change detection stay
    on kb-4m5.

17. **`kourob init` ships a working starter** — `note.v1`, a T0 rule, and fixtures including
    deliberately bad lines. Without it, `kourob init && kourob ingest fixtures/events.jsonl`
    from brief §12 M1 cannot run, and GOAL.md metric 1 ("under 10 minutes to a cited
    answer") is not testable.

18. **The zone-path rail moved from `gate.py` to `store/parquet_duckdb.py`.** The rail's
    intent is "nothing reaches around the Store"; the Store backend obviously names the
    paths it maps. Only-gate-writes-silver is now checked by the gate's own tests rather
    than by grep, because grep cannot see a call.

19. **`Store.query` accepts named parameters.** A mined T0 rule binds from named capture
    groups, and making generated SQL depend on positional order is a bug waiting for a
    rule with two parameters in the wrong sequence.

20. **A T0 rule that matches the question but finds no rows is a miss, not an empty
    answer.** Silence is not a fact. The cascade falls through instead of returning
    "nothing", which would be a claim.
