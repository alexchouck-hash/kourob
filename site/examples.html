One Question, Seven Nodes

A single node is easy to picture. The point of KouroB is what happens when there are several: a question arrives at a desk that holds nothing, gets referred to the cell that does hold it, and comes back cited — with a receipt on every hop. These examples build that network on your machine in under a second, from public data, and let you ask it things.

KNP-1 · Scope & Routing

What Happens When You Ask the Front Desk

The two-hop path, step by step. This is the real output of kourob query "nws observation at KJFK" against the front desk of a freshly built network.

  1. trooth-desk — out of scope, refer

    The question matches the front desk's declared exclusion weather|temperature|humidity|wind|observation|kjfk|nws|open-meteo, which names weather-desk as the referral target. The desk holds nothing, so there is nothing to try first.

  2. weather-desk — out of scope again, refer

    The second desk splits weather by kind: \bnws\b|national weather|station|conditions goes to the station node, open-meteo|model|grid to the model node. "nws" wins.

  3. nws-node — answers at T0

    A compiled rule binds against the held observation event and answers with no model call at all: $0.00, exact replay. The answer carries the licence and how far behind the source it is.

  4. The route is handed back

    bridge_limit: 1 means the caller gets one introduction. Ask the same question again and the desk refers instead of bridging — the caller now holds the direct route and the network got shorter without anyone coordinating it.

bash — kourob query
$ kourob query 'nws observation at KJFK' \
  --node examples/trooth-network/cells/trooth-desk

Runbook

Build the Network Yourself

Seven cells from one command, in under a second. Each is kourob init plus its contracts, its T0 rules, and the fixtures it holds — no bespoke wiring.

uv run python examples/trooth-network/build.py

Initialises the five source cells, ingests each feed's envelope, Trooth's published scorecard and Modafied's emblem through the gate, then creates the two desks and connects them. Prints each cell's did:key: and event count, and writes cells/credits.md.

uv run kourob query 'largest earthquake in the last hour' --node examples/trooth-network/cells/trooth-desk

One hop instead of two: the front desk refers earthquakes straight to usgs-node. Swap the question for a CPI one and it lands on bls-node instead.

uv run streamlit run examples/trooth-network/dashboard.py -- examples/trooth-network/cells

Watch it: the cells and their routes as a live graph with each route's Hebbian strength, a question asked through serve.answer, and the receipt chain across nodes with price and cost summed along it. The dashboard reads every cell through the Store API and has no node-specific code.

Honest fixtures. The envelopes are snapshots of the real public sources — fetched, hashed, and time-stamped the way Trooth's snapshot job does it — but they are signed by a local key with key_id: kourob-local. That id is the marker: they prove what was fetched and when, by this operator, not by Trooth. They validate against Trooth's schemas, and nothing downstream changes the day real ones arrive.

Why It Matters

What the Network Demonstrates

🔀

Routing Without a Registry

No node holds a map of the network. Each desk declares exclusions and the neighbour each one refers to; a three-cell path emerges from two independent local decisions. Callers learn direct routes and stop paying for the hop.

🔗

Receipts That Cross Machines

Each hop appends its own signed receipt naming the upstream receipt it depended on. kourob trace walks the whole chain back to the immutable event — across nodes that never shared a database.

💳

Metered End to End

Price and cost are recorded per hop and summed along the chain, so "what did that answer cost, and who earned what" is a table, not an estimate — even when the answer came from three separately owned cells.

📇

A Node Is a Data Provider

kourob publish --trooth writes a catalog entry and a six-dimension scorecard for each cell, in Trooth's own schemas, computed from the node's own records. A node and a public source become comparable on one page.

📜

Credits Generated, Not Written

credits.md is produced from what the cells actually hold: every feed with its licence and attribution, every scorecard, every independently issued benchmark emblem with its notice. Rebuild it and it states what is true then.

🧪

The Example Is the Test

The test suite builds each example by calling the same build function, asks the same questions, and validates the outputs against the published schemas. An example that rots fails CI.
