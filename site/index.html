Anatomy

What is a KouroB Node?

A node is not an agent, not a chat memory, and not an LLM wrapper. It is an independent, metered, self-specializing unit of knowledge and capability.

🛡️

The Gate & Silver Store

Nothing writes to silver or gold except gate.py. Incoming facts are validated against ODCS schemas, deduplicated, stamped with ULIDs, and stored in typed Parquet tables.

Read KNP-0 Invariants →
⚡

5-Tier Cascade

A query tries the cheapest tier first: T0 (compiled rules & SQL) → T1 (distilled model) → T2 (specialized model) → T3 (frontier LLM) → T4 (human review). Frontier models train nodes; they don't serve them.

Explore the 5 Tiers →
🔗

Hash-Chained Ledger

Every request leaves an ed25519-signed receipt with request hash, response hash, tier used, citations, cost in credits, and a cryptographic prev pointer. No silent history rewrites.

Inspect Receipts →
🔀

Referral & Bridging

When a query falls outside a node's declared scope, the node refers or bridges to a neighbor. Callers learn direct routes via Hebbian route updates, finding shorter paths without a central coordinator.

Read KNP-1 Scope Spec →
🎯

Settlement From Reality

Outcomes are appended to the ledger judging past receipts without editing them. When a match ends or a test runs, source: reality provides free, unarguable training labels.

Read KNP-2 Outcomes →
🌱

Self-Specialization Loop

Scheduled evolve cycles cluster demand from the request log, mine T0 rules by exact replay, auto-split bimodal demand into child cells, and apply changes under autonomy levels (A0–A3).

Economics

The 5-Tier Execution Cascade

Every port pull executes through the cascade. A node always serves from the cheapest tier that satisfies its calibrated quality threshold.

Tier Execution Mechanism Determinism Class Typical Cost Latency
T0 · Rules & Cache Exact SQL queries over silver Parquet, compiled regex patterns, cached views exact / derived $0.0000 < 15ms
T1 · Distilled Model Compact local model (0.5B–3B params, GGUF/ONNX) fine-tuned on node's request distribution calibrated $0.0002 40–80ms
T2 · Specialized Model Mid-weight domain model (e.g. 7B–14B) hosted locally via Ollama/vLLM calibrated $0.0010 150–300ms
T3 · Frontier Model Cloud frontier LLM (Claude, GPT-4o, Gemini) called only through runner/ with grounded event context calibrated $0.0050+ 500–1500ms
T4 · Human in Loop Asynchronous review queue for transactions flagged review_required or dispute settlement exact Variable Minutes / Hours
Specifications

KNP: KouroB Node Protocols

Strict wire contracts governing what crosses the boundary between two nodes. All protocols ride on declared A2A extensions (ADR-0006) without proprietary transport forks.

KNP-0 Core Invariants

Three Invariants & Determinism

Every port handler returns {data, rendered, citations, receipt_id}. Declares four determinism classes: exact, derived, calibrated, and declared.

  • I1: The Port Invariant — identical envelope across MCP, A2A, and REST.
  • I2: The Citation Invariant — every claim cites an event id.
  • I3: The Receipt Invariant — all model calls generate a signed receipt.
KNP-1 Scope & Routing

Scope, Refusal, Referral & Bridging

Nodes declare what they answer. Out-of-scope calls return a referral with route hints or execute a bridge hop with upstream receipt chaining.

  • Refusals carry reasons: unsupported domain, budget exceeded, rate limit.
  • Bridging transfers route hints so callers learn direct paths.
  • Hop-list loop prevention stops circular node cascades.
KNP-2 Provenance & Ledger

Receipts, Hash Chains & Outcomes

Append-only Parquet receipt ledger hash-chained by prev. Outcomes judge past receipts without editing them, settled by source: reality.

  • Receipts hash requests and responses; they never leak private bodies.
  • Settlement keys match subsequent facts to historical answers.
  • Full export to W3C PROV-O ontology for third-party verification.
KNP-3 Metering & Economics

Quotes, Ceilings & Accounts

Price function = base × (1 + demand) × earned_quality. Quotes return a ceiling that the final receipt is guaranteed never to exceed.

  • Measured token costs logged via runner adapters to calls.parquet.
  • Callers receive free allowance followed by post-paid debits.
  • Unmeasured nodes price at q_min floor until receipts settle.
KNP-4 Discovery & Trust

Registries & Hebbian Routes

Route tables learn neighbor strengths through success. Hearsay starts at weight 0.4, operator connections at 0.5, incremented upon successful settlement.

  • Sets share a trust root (did:key) over multiple child nodes.
  • Cross-set referrals evaluate caller reputation and credit terms.
KNP-5 Evolution & Lifecycle

Rule Mining, Promotion & Auto-Split

T0 rules promote strictly on 100% exact replay over settled requests. One single correction demotes a rule immediately. Bimodal demand triggers auto-split.

  • Rules require zero parameter hallucination.
  • Auto-split creates independent child manifests resetting to A0.
  • Scope shedding purges unaccessed schemas under memory bounds.

Developer CLI

Command Line Interface

Everything in KouroB is operated through the unified kourob CLI tool.

kourob init <path> [--template default]

Lays down a complete, working KouroB cell. Generates an ed25519 identity keypair, creates the DuckDB/Parquet store layout (data/raw, data/silver, data/gold), initializes the ledger, and configures starter schemas and rules.

kourob ingest <file.jsonl> [--node .]

Pushes raw events through gate.py. Validates against declared ODCS schemas, stamps each record with a ULID (evt_...), hashes content, segregates invalid rows into quarantine, and appends valid rows to data/silver/events.parquet.

kourob query "<question>" [--tier auto] [--format json]

Executes a query through the node's cascade. Evaluates declared scope, cascades through T0–T3, prints the rendered text with citations, and outputs the generated receipt ULID.

kourob serve [--mcp] [--a2a] [--rest] [--port 8000]

Launches the node transport listeners. --mcp starts the stdio server for Claude Code and Cursor; --a2a starts the Google A2A protocol server with KNP extensions; --rest exposes OpenAPI HTTP endpoints.

kourob trace <receipt_id> [--format prov-json]

Reconstructs the full cryptographic provenance chain for an answer. Displays the receipt, verifies the ed25519 signature and prev hash, walks citations back to silver events, and resolves any upstream node hops.

kourob tend [--autonomy-max A2] [--dry-run]

Runs the autonomous maintenance loop: ingests pending facts, runs evolve, evaluates mined proposals against the autonomy ceiling and budget, applies changes as reversible node_change.v1 events, and halts/demotes on quality breach.

kourob meter report [--window 30d]

Generates the financial audit report. Compares measured token costs from calls.parquet against credits billed, breaks down request volume across T0–T4 tiers, calculates operating margin, and displays earned quality multipliers.
